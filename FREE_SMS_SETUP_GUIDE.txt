TROUBLESHOOTING
================================================================

If SMS not sending:
1. Check API key is correct in send-sms.php
2. Check lines 163-165 are uncommented
3. Verify phone number format (9893372352)
4. Check Textlocal dashboard for error logs
5. Ensure WAMP/PHP curl extension is enabled

Enable curl in WAMP:
1. Open php.ini file
2. Find: ;extension=curl
3. Remove semicolon: extension=curl
4. Restart WAMP server
